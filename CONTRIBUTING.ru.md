# Внесение изменений

[English](CONTRIBUTING.md)

Используйте отдельную ветку и PR. Слияние выполняет владелец. Прочитайте AGENTS.md и закреплённую политику репозитория. В том же PR обновляйте оба README и относящуюся к изменению английскую/русскую документацию. Сохраняйте границы задачи, авторство и уведомления.

Подготовьте проверки: `npm ci --prefix .standards --ignore-scripts --no-audit --no-fund`, затем `node .standards/install-gitleaks.mjs` и `node .standards/install-hooks.mjs`. Hook сохраняет предыдущие hooks и проверяет индекс без повторного добавления файлов. Запускайте `node .standards/check.mjs structure` и `node .standards/check.mjs staged`. Используйте закреплённый Prettier с `.standards/format.json` и gofmt для Go.

Выполняйте команды docs/ru/guide.md на изолированной инфраструктуре. Обычные тесты не должны обращаться к официальному сервису, менять сеть или использовать физическое устройство. Не исполняйте недоверенные публичные PR на приватном runner. После проверенной сборки публикуйте доказательства точного исходника статусом `software-verification`; физическая приёмка учитывается отдельно.
