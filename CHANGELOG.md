# Candidate capabilities

## 0.2.0-rc.3

The candidate provides an offline Go server and diagnostic panel, compatible VacuGlide 2 speed/valve/script/slot APIs, local native catalog import, bounded script conversion/transfers, and a verified-TLS loopback simulator. Windows supports an explicit-start access point or router-assisted network; Docker runs the core with local configuration and persistent data.

Control uses explicit pairing, independent local authentication, opt-in external writes/scripts, cancellation and confirmed protocol STOP. State writes are atomic; requests, uploads, event streams and stores have bounds. Client and protocol tests use synthetic firmware. English and Russian documentation covers current installation, configuration, API, data recovery and development.

This is an experimental candidate, not a stable release. Physical playback/valves, installed network paths and target recovery remain unaccepted. See [verification](docs/en/verification.md) and [license status](LICENSE.md).

Кандидат включает автономный Go-сервер и диагностическую панель, совместимый API скорости/клапанов/сценариев/слотов VacuGlide 2, импорт штатного каталога, ограниченные преобразование/передачу сценариев и loopback-симулятор с проверкой TLS. Windows поддерживает явный запуск точки доступа или сеть с настроенным роутером; Docker запускает ядро с локальной конфигурацией и постоянными данными.

Управление использует явную привязку, независимый локальный ключ, отдельное включение внешней записи/сценариев, отмену и подтверждённый протокольный STOP. Записи состояния атомарны; запросы, загрузки, события и хранилища ограничены. Клиентские и протокольные тесты используют виртуальную прошивку. Документация на русском и английском описывает текущую установку, конфигурацию, API, восстановление данных и разработку.

Это экспериментальный кандидат, а не стабильный выпуск. Физическое воспроизведение/клапаны, установленные сетевые маршруты и восстановление на целевых платформах ещё не приняты. См. [проверки](docs/ru/verification.md) и [статус лицензии](LICENSE.md).
