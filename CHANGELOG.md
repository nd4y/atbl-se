# Changelog

## 0.2.0-rc.3 rename and standard review candidate

Renamed project-owned entry points, module, artifacts and settings to atblse. Added non-destructive Windows state migration; revoked disconnected device credentials and streams; bounded upload admission; atomic state commits; complete bilingual package notices and checks that remain active under optimized Python. Physical acceptance and stable release remain open.

Переименованы собственные команды, модуль, артефакты и настройки в atblse. Добавлены миграция Windows с сохранением исходника, отзыв токена и потоков отключённого устройства, ограничение загрузок, атомарная запись состояния, полные уведомления и документация в пакетах, проверки упаковки при оптимизации Python. Физическая приёмка и стабильный выпуск остаются открыты.

## 0.2.0-rc.2 source publication candidate

Standalone core and diagnostic panel; script and slot API compatibility; cancellation, immutable transfer grants and panel renewal fixes; verified Windows shutdown ownership and build provenance. Added a loopback-only virtual-device CLI and ephemeral local lab. Source publication does not mark physical acceptance or a stable release.

Кандидат публикации включает ядро, панель, совместимые сценарии/слоты, исправления STOP/передачи/продления, проверку владельца Windows-процесса и происхождения сборки. Добавлены виртуальный клиент только для loopback и временный локальный стенд. Публикация исходников не означает физическую приёмку или стабильный релиз.
