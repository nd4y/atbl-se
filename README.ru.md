# atblse

[English](README.md)

![Локальный сервер и виртуальный VacuGlide](docs/assets/preview.svg)

**atblse - Autoblow Server Emulator** позволяет управлять VacuGlide 2 со штатной прошивкой через локальный сервер. В проект входят веб-панель диагностики и совместимый API для приложений, например VacuGlide Studio.

- Работает без интернета и облачного аккаунта, когда приложение и конфигурация уже сохранены локально.
- Управляет скоростью, обоими клапанами, 30 слотами устройства и синхронным воспроизведением Funscript/CSV.
- Запускается как Go-сервер, через оболочку Windows или в Docker на NAS с отключённым автоматическим перезапуском.
- Содержит виртуальное устройство для разработки без оборудования.

Текущая версия исходников - **0.2.0-rc.3**, экспериментальный кандидат для VacuGlide 2 с прошивкой **1.03 / 1.0.3**. Физическая приёмка этой Go-реализации и Windows Hotspot остаётся открытой. AI Ultra и обновление прошивки не входят в поддерживаемый профиль.

## Попробовать без устройства

Из корня репозитория, с Go 1.24 или новее:

```sh
go build -o out/atblse-simulator ./cmd/atblse-simulator
./out/atblse-simulator --lab --duration 10m
```

В Windows укажите `-o out/atblse-simulator.exe` и запустите полученный файл. Программа выведет JSON с полями `api`, `controlToken` и `pairMAC`. Откройте `api` в браузере, введите ключ и подтвердите привязку виртуального устройства. Стенд использует временные данные и завершится через десять минут. TLS-сертификат проверяется; официальный сервис и физическое устройство не используются.

Для сборки нужны заранее скачанные зависимости или подготовленный кеш. Готовое приложение не загружает зависимости при запуске. Веб-панель и оболочка Windows сейчас имеют русские подписи.

## Подключить устройство или приложение

Выберите [Windows](docs/ru/windows.md) либо [отдельный сервер / NAS](docs/ru/guide.md). Настройте локальную сеть, подключите устройство и подтвердите привязку в панели. Во внешнем приложении задайте адрес локального сервера и ключ управления, затем явно включите нужные функции API.

По умолчанию максимальная скорость - 15%, функции сценариев выключены. Панель использует продлеваемый сеанс управления; внешние приложения сами отвечают за STOP. Подтверждение команды прошивкой не является показанием физического датчика.
