# Сообщения об уязвимостях

[English](SECURITY.md)

Поддерживаемая область: текущий кандидат 0.2.0-rc.3 и профиль VacuGlide 2 firmware 1.03. Это экспериментальное ПО управления устройством. Используйте приватное сообщение об уязвимости в GitHub, если доступно, либо свяжитесь с владельцем приватно; в публичной задаче допустим только обезличенный пример.

Не прикладывайте локальные/облачные ключи, MAC, пароль точки доступа, каталоги данных и захваты. Раскрытый локальный ключ заменяйте при остановленном сервере и переподключайте клиентов. Слушатели API/устройства должны оставаться приватными; LAN сам по себе не даёт авторизации. Удалённое обновление прошивки не реализовано.
