## Программные проверки - 2026-10-30

Проверены исходники `8a34d860cbd5b4ed0ac77146877fa930bdc12ea4`, Go 1.27.3, Node 24.22.1, изолированная Linux-сборка с отключённой сетью для runtime-тестов. Все 524 Go-теста/подтеста прошли с race detector; `go vet` прошёл. SDK 2.6.0 и адаптер Studio проверены 57 запросами через каждый из HTTP и HTTPS. Панель: 7 проверок; кодек: 8; модель тактов: 15; упаковщик: 7; отдельный TLS/WSS-симулятор: 11 запросов, включая оба клапана, STOP, слоты и передачу сценария. Собраны команды Linux и Windows. Квитанция сборки связывает 44 файла runtime. Windows PowerShell 5.1 прошёл проверку синтаксиса, 8 синтетических сценариев миграции и 5 проверок жизненного цикла с моками; реальные адаптер и устройство не включались.

Закреплённый комплект принял корректный пример и отклонил плохое форматирование, отсутствие перевода, изменение документации только пробелами, удаление документации, сгенерированный синтетический секрет и отсутствие сканера. Staged/introduced/full-history Gitleaks 8.30.1 прошёл, включая патчи merge-коммитов. `govulncheck` v1.9.0 не нашёл достижимых уязвимых вызовов (база от 2026-10-27); npm audit не нашёл уязвимостей в обоих закреплённых наборах инструментов. Это наблюдение конкретной версии и базы, не гарантия на будущее.

После переименования GitHub повторно проверены идентичность, история, публичность и обязательные проверки защищённой main. Secret scanning и push protection включены. Для следующих версий источником текущего результата остаются статусы PR. Ревью не устанавливало приложение, не прошивало и не запускало физическое устройство, не публиковало релиз.
