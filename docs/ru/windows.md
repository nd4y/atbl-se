# Оболочка Windows

[English](../en/windows.md)

Запустите `atblse.exe`, сохранив рядом каталог `windows/` из пакета. Используйте [инструкцию установки](guide.md#установка-и-сеть) и [миграции](migration.md). Приложение не подключается к устройству автоматически. Физическая приёмка Hotspot пока не выполнена.
