# Оболочка Windows

[English](../en/windows.md) | [Конфигурация](configuration.md)

Оболочка использует Windows PowerShell 5.1, .NET Framework и WinRT. Для работы не нужны Python, WSL и Docker Desktop. Автономной сети требуется Wi-Fi-адаптер с поддержкой Wi-Fi Direct.

## Подготовка и запуск

Из корня репозитория в Windows PowerShell, с установленным Go:

```powershell
New-Item -ItemType Directory -Force out/windows | Out-Null
go build -o out/windows/atblse-server.exe ./cmd/atblse-server
go build -ldflags="-H windowsgui" -o out/windows/atblse.exe ./cmd/atblse-windows
Copy-Item -Recurse -Force windows out/windows/
Copy-Item -Recurse -Force docs out/windows/
```

Храните рядом `atblse.exe`, `atblse-server.exe`, `windows/` и `docs/`. Откройте `atblse.exe`; сервер изначально остановлен.

1. Выберите домашнюю сеть и IPv4-интерфейс либо автономную точку доступа.
2. Для точки доступа задайте SSID и пароль. Для домашней сети настройте роутер/DNS по [сетевой инструкции](guide.md).
3. Нажмите **Запустить**. Оболочка запустит свой сервер и откроет локальную панель с ключом управления.
4. При необходимости нажмите **Разрешить в брандмауэре...**. Настройка запросит повышение прав и ограничит правила приложения DNS/TLS, выбранным интерфейсом и локальной подсетью.
5. Задайте Wi-Fi через обычную настройку устройства, подключите его и подтвердите привязку в панели. Этот шаг требует физического устройства.

Панель слушает `127.0.0.1:20880`, порт устройства - 443 на выбранном интерфейсе. Автономный режим включает локальный DNS; в домашней сети для DNS есть флажок. Открытие оболочки само по себе не запускает сервер или мотор.

## Данные и параметры управления

Данные приложения находятся в `%LOCALAPPDATA%/atblse`, состояние сервера - в подкаталоге `server/`. Пароль Wi-Fi сохраняется локально. Необязательный `control-options.json` принимает только `maxSpeed`, `compatibilityControl`, `experimentalSyncScripts`, `experimentalLocalScripts` и `scriptURLOrigins`. Изменяйте его при остановленном сервере. См. [конфигурацию](configuration.md) и [восстановление данных](data.md).

## Остановка и диагностика

Нажмите **Остановить** или закройте окно. Оболочка проверит принадлежность API своему процессу и запросит завершение сервера до отключения точки доступа. Если выход процесса не подтверждён, сеть остаётся доступной для повторной попытки остановки.

Проверьте `server-error.log`, `hotspot-error.log` и `launcher-startup.log` в каталоге приложения. Ошибки запуска исполняемого файла записываются в `%LOCALAPPDATA%/atblse-launcher-error.log`. Не публикуйте сырые журналы с личными путями и конфигурацией. Открытие интерфейса не подтверждает работу Hotspot и устройства; см. [состояние проверок](verification.md).
