# Паспорт проекта и приёмка

[English](../en/project.md)

**Продукт:** отдельный автономный сервер управления устройством и панель диагностики, кандидат 0.2.0-rc.3; экспериментальный жизненный цикл. Пользователи - владельцы VacuGlide 2 со штатной прошивкой и разработчики совместимых клиентов.

| Сценарий                  | Ожидаемый результат                                                 | Приёмка                                                                                  |
| ------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Локальное подключение     | Идентификация, явное сопряжение, независимый локальный ключ         | TLS/WSS и запрещённая авторизация проверяются тестами; физический сетевой путь открыт    |
| Управление из приложения  | Подтверждённые скорость/клапаны/сценарии/слоты и STOP               | Контракты официального SDK 2.6.0 и снимка HTTP-адаптера Studio с виртуальным устройством |
| Разработка без устройства | Стенд на loopback, синтетические ответы и локальная передача файлов | Интеграция отдельного симулятора и некорректные входные данные                           |

Переносимый Go-сервер отвечает за WSS, HTTP/SSE, DNS, локальную авторизацию и хранение сценариев. Windows управляет жизненным циклом Wi-Fi Direct и брандмауэра. Docker независимо запускает ядро. Нативные оболочки Linux/macOS и Android-хостинг предусмотрены архитектурой, но не реализованы. При запуске не нужны облачный аккаунт, registry или сессия браузера.

Постоянные данные: локальный ключ управления, сопряжение, конфигурация, импортированные сценарии. Windows дополнительно хранит пароль своей точки доступа. Перед копированием целых приватных каталогов данных/конфигурации остановите процесс; прежде чем полагаться на копию, проверьте изолированное восстановление. Сырые данные не подходят для приложения к задачам. Релизные артефакты должны связываться с точными исходниками; первый PR исходников не означает стабильного публичного релиза или автоматической установки.

Профиль реализует 26 операций управления, исходные ID каталога и бинарную передачу. Аккаунты, видеокаталог, сообщество, AI и OTA исключены. Явные отличия локальной политики: сопряжение, флаги управления/сценариев, список разрешённых источников URL, ограничение хранения и самостоятельное управление данными. См. машиночитаемый контракт.

Точная версия исходников и программные доказательства приведены в [ревью по стандарту](review-2026-10-29.md). После изменения исходников обязательные статусы PR проверяются заново; количество тестов не подтверждает физическую совместимость.

**Не проверено:** физическое воспроизведение и клапаны Go-кандидата, Windows Hotspot целиком, холодный старт и потеря питания/сети на устройстве, полная доступность интерфейса, чистая установка/обновление/восстановление на целевых физических системах и масштаб сверх измеренных границ. Общая задача repository-standard не подтверждает эти результаты.

Ограничения: одно подключённое устройство, 30 штатных слотов, 128 импортированных записей каталога, 100000 исходных Funscript-точек и ограниченная бинарная передача. Бюджет Docker-кандидата 96 MiB/0.5 CPU является условием теста, а не обещанием производительности. Сеанс панели длится 1..3600 секунд и имеет двухсекундный keepalive. Физическая остановка после потери контроллера/связи не гарантируется. До целевой приёмки не обещаются стабильные SLA, время восстановления или допустимая потеря данных.

Поддержка относится к описанному кандидату и профилю прошивки. В задачах указывайте версию, обезличенную конфигурацию, ожидаемый/фактический результат и синтетический пример. Не прикладывайте токены, каталоги данных целиком, захваты сессий, образы производителя или видеотеку. Историческая приёмка прототипа не подтверждает текущую сборку.
