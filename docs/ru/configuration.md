# Конфигурация сервера

[English](../en/configuration.md) | [Установка](guide.md)

Передайте JSON через `atblse-server --config server.json`. Неизвестные поля и данные после JSON отклоняются. Ниже приведены значения отдельного сервера при пропущенных полях; пример NAS и Windows-оболочка явно меняют адреса и пути данных.

| Поле JSON                  | По умолчанию      | Назначение                                                                              |
| -------------------------- | ----------------- | --------------------------------------------------------------------------------------- |
| `deviceListen`             | `0.0.0.0:443`     | TLS-listener WSS устройства, бинарных файлов и совместимого API                         |
| `apiListen`                | `127.0.0.1:20880` | HTTP-listener панели, локального и совместимого API                                     |
| `dnsListen`                | `""`              | Адрес необязательного UDP/TCP DNS; пустая строка выключает его                          |
| `dnsAnswer`                | `""`              | Приватный или loopback IPv4 для ответов DNS                                             |
| `dataDir`                  | `data`            | Приватный каталог состояния; относительный путь считается от рабочего каталога процесса |
| `maxSpeed`                 | `15`              | Целое 1..100; предел ручной скорости и загрузки синхронных сценариев                    |
| `allowShutdown`            | `false`           | Разрешить авторизованный POST /api/shutdown                                             |
| `compatibilityControl`     | `false`           | Разрешить запись внешних клиентов после локальной привязки                              |
| `experimentalSyncScripts`  | `false`           | Включить API синхронных сценариев                                                       |
| `experimentalLocalScripts` | `false`           | Включить API штатных слотов/сценариев                                                   |
| `scriptURLOrigins`         | `[]`              | Разрешённые HTTP(S) origin для импорта сценариев, не более 32                           |
| `compatibilityCluster`     | `""`              | Необязательный host[:port], сообщаемый совместимому клиенту                             |
| `tlsCertificateFile`       | `""`              | Путь к PEM-сертификату; задаётся вместе с tlsPrivateKeyFile                             |
| `tlsPrivateKeyFile`        | `""`              | Путь к приватному PEM-ключу; не публиковать                                             |

## Работа функций

Панель после привязки может запустить ограниченный ручной сеанс без включения совместимого API записи. Запись внешнего клиента требует `compatibilityControl` и привязки. Флаги сценариев включают соответствующие маршруты. Воспроизведение штатных слотов требует `maxSpeed: 100`; загрузка и load-token синхронного сценария сверяют его закодированную пиковую скорость с `maxSpeed`. Совместимый STOP доступен и при выключенных функциях воспроизведения. Тела запросов и различия остановки описаны в [API](api.md).

Пустой `scriptURLOrigins` запрещает импорт по URL. Origin содержит схему, узел и необязательный порт, без учётных данных, запроса и пути. Перенаправления запрещены. Для источника в LAN укажите явно разрешённый приватный IP; DNS-имена, разрешающиеся в приватный или loopback-диапазон, отклоняются. Загрузчик не передаёт токены устройства, cookies и заголовки авторизации.

Без путей сертификата сервер создаёт самоподписанный TLS-сертификат при запуске. Клиенту с проверкой TLS нужны настроенный сертификат и доверенный CA; проверку отключать не следует. Оба пути сертификата/ключа задаются вместе. HTTP-управление должно оставаться в приватной сети.

## Лимиты приёма и хранения

- Одно подключённое устройство, 30 штатных слотов.
- 32 обычных HTTP-обработчика, две параллельные загрузки сценария. Перегрузка возвращает HTTP 429. STOP/завершение сервера обходят обычную квоту, но требуют авторизацию.
- 32 подписчика событий, очередь 16 событий на подписчика; медленный подписчик отключается.
- Чтение заголовков HTTP: 5 секунд; запроса: 15 секунд. Получение URL: суммарно 15 секунд с ограничением ответа.
- Вход сценария: 4 MiB и не более 100000 Funscript-точек. Время в бинарном файле: 0..16777214 мс. Каждое локальное хранилище ограничено 128 записями; незавершённые временные файлы тоже учитываются.

Это ограничения реализации, а не измеренные гарантии производительности. См. [проверки](verification.md).
