# API и протокол устройства

[English](../en/api.md) | [Конфигурация](configuration.md)

Ядро предоставляет локальный API панели и совместимый API управления для внешних приложений. [Машиночитаемый контракт](../contracts/vacuglide2-control-api.json) содержит все 26 совместимых операций и статус их проверки. Целевое устройство - VacuGlide 2 со штатной прошивкой `1.03`/`1.0.3`. Аккаунты, видеохостинг и OTA в этот API не входят.

## Авторизация и подключение клиента

| Интерфейс                 | Авторизация                         | Назначение                                                   |
| ------------------------- | ----------------------------------- | ------------------------------------------------------------ |
| `/health`, файлы панели   | Без авторизации                     | Версия/доступность и статический UI; без секретов управления |
| `/api/*`                  | `Authorization: Bearer <local-key>` | Панель и локальное администрирование                         |
| Совместимые HTTP-маршруты | `x-device-token: <local-key>`       | Независимый локальный доступ, включая статус без устройства  |
| Совместимые HTTP-маршруты | `x-device-token: <device-token>`    | Действует только при подключённом устройстве                 |
| `/events/stream`          | Параметр запроса `deviceToken`      | SSE с теми же правилами локального ключа/токена устройства   |

Локальный ключ находится в `dataDir/control-token`. Токен прошивки хранится только как хеш в памяти; отключение отзывает доступ и привязанные к устройству потоки событий. Не включайте URL с ключом в журналы или отчёты об ошибке.

В клиенте, например VacuGlide Studio, укажите локальный адрес сервера и ключ, если его настройки подключения это позволяют. Приложению с жёстко заданным облачным адресом нужна собственная поддержка локального адреса или проверенная настройка сети. Включённый в тесты адаптер Studio проверяет HTTP-поведение; он не доказывает совместимость любой установленной версии Studio без изменений. Контракты проверяются через HTTP и HTTPS. HTTPS-клиент должен доверять настроенному сертификату; оставляйте проверку сертификата включённой.

Подтвердите подключённый MAC в панели. Для записи через внешний клиент задайте `compatibilityControl: true`, а для сценариев включите соответствующий флаг. По умолчанию доступны просмотр состояния и ограниченное управление через панель после привязки. Внешний клиент отвечает за свой STOP: его запуски не используют двухсекундное продление панели. STOP требует авторизации даже при выключенных флагах воспроизведения.

## Локальный API панели

| Метод и путь          | Вход / результат                                                                         |
| --------------------- | ---------------------------------------------------------------------------------------- |
| `GET /api/status`     | Подключение, привязка, текущий `generation`, ограничения и состояние управления          |
| `GET /api/state`      | Запрос состояния подключённого устройства                                                |
| `POST /api/pair`      | `{"mac":"020000000001"}` для виртуального устройства; иначе фактический подключённый MAC |
| `POST /api/start`     | `{"speed":15,"seconds":60,"generation":1}`; подставляйте актуальный generation           |
| `POST /api/keepalive` | `{"controlEpoch":"<значение из ответа start>"}`                                          |
| `POST /api/stop`      | Безопасный STOP: отмена ожидающих операций, пауза мотора и закрытие обоих клапанов       |
| `POST /api/shutdown`  | Только при `allowShutdown: true`; безопасная остановка и завершение сервера              |

Start принимает целую скорость `1..maxSpeed` и длительность `1..3600` секунд. Панель продлевает выданный epoch каждые 400 мс. Продление не увеличивает исходную длительность. Устаревшее поколение подключения или истёкший/заменённый epoch не возобновляют запуск. При прекращении продления через две секунды сервер пытается остановить устройство; после потери связи это не гарантирует физическую остановку.

`stopConfirmed` означает подтверждение прошивки, а не показание физического датчика. Ответ health подтверждает версию сервера, а не подключение устройства. Статус подключения проверяется отдельно.

## Совместимые операции

| Группа                  | Маршруты и поля запроса                                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обнаружение/состояние   | `GET /vacuglide/info`, `/vacuglide/state`, `/vacuglide/connected`, `/autoblow/connected`, `/cluster/time`                                           |
| Ручная скорость         | `PUT /vacuglide/target-speed` с `targetSpeed`; `PUT /vacuglide/target-speed/stop`                                                                   |
| Клапаны                 | `PUT /vacuglide/valve/stroke-plus` или `/stroke-minus` с логическим `valveState`                                                                    |
| Штатные сценарии        | `PUT /vacuglide/local-script` с `localScriptIndex`; суффиксы `/start`, `/stop`; `GET /vacuglide/local-script/loaded`                                |
| Изменения слотов        | `PUT /vacuglide/local-script/replace`, `/swap`, `/move`                                                                                             |
| Загрузка синхросценария | `PUT /vacuglide/sync-script/upload-funscript`, `/upload-csv`, `/upload-funscript-url`, `/upload-csv-url`                                            |
| Синхровоспроизведение   | `PUT /vacuglide/sync-script/load-token` с `scriptToken`; `/start` с `startTimeMs`; `/stop`; `/offset` с `offsetTimeMs`; `/loop` с логическим `loop` |
| События                 | `GET /events/stream?deviceToken=<key>`                                                                                                              |

Для совместимого ручного STOP отправляйте пустое тело без `Content-Type: application/json`. Пустой JSON-запрос с таким заголовком или `{}` меняет путь проверки официального API. Для загрузок и изменений слотов используйте формы запросов закреплённого SDK; [интеграционные примеры](../../scripts/client-contracts.mjs) проверяют полные последовательности и крайние случаи.

Ручная скорость - `0..100`, ограничена `maxSpeed`. Активация штатного сценария требует `experimentalLocalScripts` и `maxSpeed: 100`: сценарии в прошивке могут использовать весь диапазон. Синхросценариям нужен `experimentalSyncScripts`; их максимальная скорость должна укладываться в `maxSpeed`. Операция `/local-script/loaded`, похожая на чтение, по поведению прошивки переводит устройство в паузу штатного сценария. Замена слота изменяет постоянное содержимое устройства; сам импорт файла в локальный каталог не отправляет команд устройству.

URL-загрузка требует явной записи в `scriptURLOrigins`. Перенаправления запрещены, заголовки авторизации клиента не пересылаются. Ограничения адресов и размеров описаны в [конфигурации](configuration.md). Сервер сохраняет преобразованные синхросценарии локально и выдаёт устройству ограниченную передачу файла; скачивание из облака при воспроизведении не требуется. Импорт штатных файлов описан в [данных и инструментах](data.md).

Ошибки различают проверку запроса/авторизацию, выключенные функции, отсутствие устройства, лимиты приёма и тайм-ауты ответа. Проверяйте статус и тело ответа. После тайм-аута не повторяйте изменяющую операцию вслепую: сначала прочитайте состояние. Ответы сопоставляются с текущим соединением; успешный синтетический ответ не доказывает поведение оборудования.

## Формат протокола и клапаны

Устройство подключается к `/device-backend/ws` через TLS, обычно через `latency.autoblowapi.com` на порту 443. Проверяются заголовки модели, поддерживаемой прошивки, MAC и токена. Локальные DNS/маршрутизация доставляют соединение ядру без изменения прошивки.

```text
/target-speed-set/15/<uuid>
/target-speed-stop/<uuid>
/valve-stroke-plus-set/1/<uuid>
/valve-stroke-minus-set/0/<uuid>
/state/<mode>/<slot>/<speed>/<plus>/<minus>/<time>/<offset>/<loop>/<token>/<uuid>
```

Режимы 43/44 означают ручное воспроизведение/паузу, 41/42 - штатный сценарий, 60/70 - синхросценарий. При паузе может сохраняться заданная скорость. Совместимый STOP сценария может сохранять состояние клапанов; безопасный STOP панели закрывает их отдельно.

Штатный файл содержит восьмибайтовый little-endian заголовок (ID сценария, маркер 1) и шестибайтовые записи: `uint32 milliseconds`, `uint8 opcode`, `uint8 value`. Opcode 0 задаёт скорость, 1 управляет stroke-minus, 2 - stroke-plus. Сохраняйте порядок и совпадающие временные метки. Автономный декодер сохраняет неизвестные записи; валидатор импорта сервера допускает только поддержанные opcodes и проверяет порядок, время и значения. Позиции Funscript преобразуются в скорость и не позволяют восстановить события клапанов. Для точного времени клапанов сохраняйте штатные бинарные записи.
