# Security reporting

[Русский](SECURITY.ru.md)

Supported scope: the current 0.2.0-rc.3 candidate and VacuGlide 2 firmware 1.03 profile. This is experimental device-control software. Prefer GitHub private vulnerability reporting when available, or contact the repository owner privately; public issues must contain only sanitized reproductions.

Do not attach control tokens, cloud credentials, MAC identities, hotspot passwords, state directories or captures. Rotate a disclosed local key with the service stopped and reconnect clients. Keep API/device listeners private; LAN access alone is not authorization. No remote firmware updates are implemented.
